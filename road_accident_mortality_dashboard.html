คู่มือการอัพโหลดขึ้น GitHub Pages สำหรับนำไปใช้งานจริง

คุณสามารถนำไฟล์ index.html นี้ไปใช้งานบน GitHub ได้ทันทีโดยไม่ต้องติดตั้ง Server เพิ่มเติม

  1. สร้าง Repository ใหม่บน GitHub.com (ตั้งค่าเป็น Public)
  2. สร้างไฟล์ชื่อ index.html แล้ววางโค้ดทั้งหมดในหน้านี้ลงไป
  3. ไปที่แท็บ Settings > Pages
  4. ตรงหัวข้อ Build and deployment ใต้ส่วน Branch ให้เลือกเป็น main (หรือ master) และเลือก / (root) จากนั้นคลิก Save
  5. รอระบบรัน 1-2 นาที Dashboard สาธารณสุขของคุณจะออนไลน์พร้อมลิงก์ใช้งานทันที!
